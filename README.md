# Square Race Game

A physics-based racing game built with Python and Pygame.

## About
This is a learning project to develop a game similar to Square Race, where colored squares bounce through obstacle courses using realistic physics.

## Development Status
🚧 **In Progress** - Currently in early development

## Tech Stack
- Python 3.12
- Pygame 2.6.1

## Setup
1. Clone the repository
2. Create virtual environment: `python -m venv venv`
3. Activate: `source venv/Scripts/activate` (Git Bash on Windows)
4. Install dependencies: `pip install pygame`
5. Run: `python src/main.py`
